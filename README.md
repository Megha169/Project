**Retail Sales Analysis**

**Project Overview:**
This project focuses on analysing retail sales transactions and demonstrates the use of Power Query, Excel, SQL and Power BI to transform retail transaction data into meaningful business insights. The analysis was conducted to understand the revenue trends, sales performance across different product category, genders and age group.

**Tools & Technologies:**
Power Query, Microsoft Excel, MySQL and Power BI.

**Dataset:**
**Source:** Kaggle – Retail Sales Dataset
The dataset contains retail transaction information, including:
•	Transaction ID and Date
•	Customer ID
•	Gender and Age
•	Product Category
•	Quantity Sold
•	Price per Unit
•	Total Sales Amount
